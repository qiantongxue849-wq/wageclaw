## 2. 核心功能与交互细节落实

### 2.1 桌宠常驻与交互协议
- **视觉主体**：使用经过裁剪提炼的旧版卡皮巴拉精灵图（`capybara-idle.webp`、`capybara-play.webp`、`capybara-sleep.webp`），静止待机为主，间歇动画在下班前执行 `play`，下班/休息日执行 `sleep`。
- **窗口透明与点击穿透**：`PetView.vue` 内置 Canvas 288×288 像素透明度检测（Alpha > 18），鼠标在透明边缘自动触发 `pet:hit(false)`，通过 `win.setIgnoreMouseEvents(true, { forward: true })` 穿透至下层桌面，不挡其他应用。
- **手势防抖与点击分离**：
  - 指针位移 > 6px 判定为拖动，取消点击计时；拖动松开后通过 `electron` 记录坐标并持久化。
  - 单击等待 450ms 双击窗口；若在此期间触发第二次点击，立即取消单击并调用 `desktop.openMain()` 打开详情面板。
  - 单击触发播报气泡（防抖 2 秒）。
- **右键菜单与托盘**：包含“查看详情（双击桌宠）”、“立即播报”、“暂停一小时”、“今天安静”、“恢复播报”、“设置”、“隐藏/显示桌宠”、“退出”。隐藏后随时可从托盘恢复。

### 2.2 不定期轻量播报引擎
- **纯函数候选集**（`broadcast.ts`）：覆盖今日收入、距离下班、休息日、公共假期倒计时、个人春节倒计时、年终奖预计发放。未配置的字段绝不虚构。
- **隐私模式立即生效**：开启“隐藏金额”后，今日收入文案自动脱敏为“今天的付出，已经慢慢变成回报。”，不含任何数字。保存设置时立即触发气泡 `dismiss()` 并重绘。
- **调度频次控制**：
  - 普通随机播报：工作时间内间隔 60～120 分钟，每日最多 3 次。
  - 关键节点：下班前 30 分钟（priority 2）、到点下班（priority 3），各最多 1 次。
  - 节点前后 15 分钟内静音，避免普通播报撞车。
  - 每日所有自动播报合计最多 5 次，且任意自动播报间距 ≥ 20 分钟。
  - 过期防补发：过期超过 2 分钟的提醒自动废弃，休眠唤醒后重排未来计划，绝不在深夜集中补发。
- **首次与完成引导**：
  - 未配置首次启动：桌宠展示一次欢迎气泡“点我看一句，双击看全部。先填好工资和作息，让盼头开始。”
  - 填完保存后：自动关闭面板，展示提示“点我看一句，双击看全部；拖动可换位置。”

### 2.3 架构解耦与按需面板
- **独立运行服务**：`electron/desktop-service.cjs` 统一持有状态、调度器、窗口句柄与单例锁；面板关闭后完全销毁窗口与其渲染进程，释放 WebContents 资源。
- **纯函数领域计算同源**：通过 `scripts/build-core.mjs`（esbuild）将 `src/lite/desktop-core.ts` 编译为 `electron/generated/core.cjs`，主进程与渲染进程共享同一份计算逻辑。
- **原子存储与备份**：`desktop-store.cjs` 采用 `.tmp` 临时文件落盘再 `renameSync` 原子替换，并在重置或覆盖导入前自动生成带时间戳的完整备份文件。

## 6. 技术路线结论

- **当前阶段结论**：当前基于精简版 Electron 已完全达到 V2 规划的体验与功能闭环，且前端构建产物大幅收敛。
- **后续评估标准**：若后续启动 Tauri 2 原型验证，需严格按照文档要求在同一测试机对比完整进程树常驻内存（全进程树内存降低约 30%）、CPU 唤醒频率及跨平台透明穿透表现后再做正式发布决策。
