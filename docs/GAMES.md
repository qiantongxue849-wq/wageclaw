# WageClaw 小游戏方案

> 2026-08-30 V2 体验方案（`docs/GAMES_UX_OPTIMIZATION_V2.md`）落地后的现行结构。
> 引擎：`src/composables/games.ts`；壳层与舞台：`src/components/games/`（GameShell 大厅 各游戏组件）；样式：`src/styles.css` V2 区段。
> 新增机制：新手两步教学（首局教跳教蹲）、失焦自动暂停+倒数恢复、摸鱼连段加成、撞击冻结 250ms、统一退出确认与结算卡、大厅每日任务进度与爪币额度展示。

## 通用系统

| 机制 | 说明 |
|------|------|
| 爪币奖励 | 全部走 `addPawCoins(..., "event")`，共享「事件桶」每日上限 140 爪币，领满后只提示不再发放 |
| 每日任务联动 | 每局结束触发 `onGameEnd` → 计入「完成 1/3 局桌面小游戏」任务 |
| 成就联动 | 战绩字段（胜场/连击/闯关最佳）直接喂给成就判定，如「初次反击」「怨念体克星」「连击艺术家」「怨气闯关高手」 |
| 键盘操作 | 全局键盘监听统一在 `useWageClaw`：格斗 J/K/I/L/H/Shift/Q/E，跑酷 空格/↑/W 跳、↓/S 蹲 |
| 代码结构 | 引擎是依赖注入工厂（`createDuelGame` / `createGomokuGame` / `createRunnerGame`），只维护逻辑 + fx 表现状态；DOM 呈现交给 `GameModals.vue` |

## 1. 桌面切磋（回合制格斗）

**规则**：你和软团组队 vs 老板怨念体，双方 100 血，energy（爆发）起手 42。

| 招式 | 键 | 伤害 | 消耗 | 回充 |
|------|----|------|------|------|
| 普通拳 | J | 10 | 0 | +12 |
| 反弹脚 | K | 16 | 0 | +9 |
| 嘴替暴击 | I | 24 | 24 爆发 | +4 |
| 怨气波 | L | 30 | 36 爆发 | 0 |
| 安抚回血 | H | 回 18 | 22 爆发 | 0 |
| 格挡 | ⇧ | 0 | 0 | +18 |
| 闪身 | Q/E（键盘隐藏招，无按钮位） | 4 | 8 | +10 |

**数值成长**：
- 暴击率固定 15%，伤害 ×1.6
- 我方伤害加成 = 2 + 桌宠等级 × 0.6
- 敌方伤害减免 = min(6, 等级 × 0.5)——养成越深越容易赢
- 敌方伤害 = 9 + 随机(10) − 减免；格挡时只吃 40%

**节奏**：我方出手后 300ms 敌人才还手（留出演示动画的窗口），boss 的命中再延迟 200ms 落地。

**表现层**：
- 双侧渐变血条（绿=你、红=boss），0.32s 平滑掉血；爆发条独立满宽（琥珀色）
- 动作位演出：物理攻击突进、怨气波施法发光、回血上浮绿光、格挡护盾环、受击抖动、倒地变灰
- 伤害飘字：命中白字、暴击橙色大字、治疗绿字、受击红字、格挡灰字，0.95s 上浮消散
- 暴击与怨气波命中触发屏幕震动（0.32s）
- 连击 ≥2 时头部弹出「连击 xN」徽章（弹跳入场）
- 胜负结算幕：胜利绿/失败红大字 + 奖励文案，boss 被击败倒地变灰

**奖励**：胜利 +25 爪币；胜/负/最大连击写入桌宠档案（`battleWins`/`battleLosses`/`battleBestCombo`）并记桌宠日志。

## 2. 五子棋

**规则**：15×15，玩家执黑先行，横/竖/两斜连成五子获胜。

**AI**：单步贪心——候选空位打分 = 中心贴近分（10 − 曼哈顿距离）+ 八邻检查（敌子 +6、我子 +5），取最高分落子。思考时间 420ms。

**表现层**：
- 纯 CSS 木纹棋盘：网格线 + 天元/四星位，零图片
- 立体渐变棋子，落子弹跳入场动画（0.22s）
- 最后一手红点标记
- 己方回合悬停显示半透明影子棋子（AI 回合棋盘锁定）
- 连成五子后获胜连线金色脉冲高亮
- 回合指示器：你执黑 / 软团思考中…（动态省略号）

**奖励**：胜 +20、平局 +8 爪币。胜负平战绩只保留在本次会话内（不跨重启）。

## 3. 怨气闯关（跑酷）

**规则**：90ms 一帧，玩家固定在跑道左侧 15%。障碍从右侧生成向左移动，进入判定带（x ∈ 8%~20%）时检查姿势：

| 障碍 | 类型 | 应对 |
|------|------|------|
| 会议📅 / 甩锅🍳 / 周报📊 | 地面（红色） | 跳跃（滞空 480ms） |
| 临需⚡ / 已读👁️ | 空中（蓝色） | 下蹲（340ms） |

姿势不对 → 撞飞结算。躲过一个障碍 +5 分。

**计分与难度**：
- 每帧 +1 分（下蹲帧 +2）；跳跃 +8、下蹲 +5
- 速度 = 1 + min(1.8, ⌊分数/120⌋ × 0.2)，最高 2.8 倍（HUD 显示倍率标签）
- 生成间隔随速度缩短（22~38 帧 ÷ 速度）

**表现层**：滚动地面条纹 + 云朵天空、跑动颠簸动画、跳跃上抛 / 下蹲压扁形变、撞飞时旋转倒地 + 场景定格 +「撞飞了！」结算浮层。

**奖励**：撞飞/撤退时结算 +min(20, ⌊分数/10⌋) 爪币；`gameBest` 持久化到桌宠档案（HUD 显示历史最佳）。

## 已知边界与后续方向

- 五子棋 AI 是单步贪心，可升级为两层极大极小（只需改 `findGomokuMove` 一个函数）
- 音效系统空缺（无音频资产），可接合成音效或免费素材
- 闪身（Q/E）只有键盘没有按钮位
- 格斗敌方回合延迟 300ms 是为动画让位，连点比旧版慢一拍
- QA 兼容性：`.duel-stage strong`、`.duel-bars` 第三个 label 的 `em`（能量数值）、技能按钮可访问名（"J 普通拳"等）是 `scripts/qa-electron.cjs` 的依赖契约，改模板时必须保留
