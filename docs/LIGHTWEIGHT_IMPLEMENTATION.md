# 轻量化改造与验证记录

## 已完成

- 用单一首页替换控制台、商城、桌宠导航，突出今日收入和下班倒计时。
- 增加公共假期、个人春节假期、预计年终奖卡片。
- 统一今日／本月收入估算，停止领取和虚拟钱包机制。
- 按本地时间直接计算，关闭、重启与唤醒后可恢复，不逐秒写存档。
- 支持每周排班、指定日期覆盖、春节假期和已核验的 2026 年假期及补班。
- 发薪日支持 1～31 和月底回退，当天全天显示今天发薪。
- 年终奖仅作为预计事项，需手动标记收到，不计入工资。
- 增加浅色／深色、金额隐藏、无登录本地使用、可选迷你窗口和置顶。
- 使用单独版本的新存档；旧存档原样保留。损坏档案有恢复入口，重置前保存备份。
- 精简 Electron IPC、托盘和窗口管理。移除旧认证、宠物演出、养成、游戏、商城和新闻代码及资源。
- 更新当前 README、架构文档；旧版说明标记为历史资料。

## 兼容与取舍

- 沿用旧版当前用户 ID 对应的工资、作息、发薪和隐私；未登录时不擅自选择或合并其他账户。
- 旧余额、爪币和心愿进度不会转换为收入；原始数据仍可导出。
- 月薪和作息改变时重新估算当月，不作为工资到账或考勤记录。
- 午休照常计入工时（不扣除、不暂停），暂不支持跨夜、分段班次和加班工资。
- 仅内置已核验的 2026 年中国大陆假期。缺失年份不推测日期，按个人排班估算并提示；个人春节日期仍可独立填写。
- 备份支持导出；首版未新增备份导入界面。
- 更新可手动检查，地址未配置时保持本地可用。

### 静态与逻辑检查

`npm run check` 全部通过：

- ESLint：无错误和警告。
- Vue / TypeScript 类型检查通过。
- 13 个领域测试通过：班次边界、月收入上限、无工作日、补班与假期优先级、个人假期、月底发薪、跨年闰年、本地日历天数、年终奖状态、无损迁移、多账号隔离、损坏存档恢复和输入清洗。
- 生产构建通过。
- `git diff --check` 通过。

旧版 50 个测试在清理旧系统前通过；与已移除养成和旧计算机制绑定的测试随功能移除，由轻量版领域测试和实际交互验证替代。

### 实际页面验证

使用本机 Chrome、独立测试档案及固定测试时间，验证通过：

- 首次设置和无登录使用。
- 实时倒计时、刷新后的收入一致性。
- 今日／本月／奖金隐私及刷新保持。
- 深色主题与 390px 窄窗口，无水平溢出。
- 1120×750 页面核心内容无需滚动。
- 跨夜班次输入被拒绝。
- 下班状态和休息日零收入。
- 备份下载、确认重置、原始值备份和损坏档案恢复。
- 无页面运行错误。

### Electron 验证

使用独立临时 user-data 目录，验证通过：

- 无需登录即可配置和使用。
- 迷你窗口创建、置顶。
- 主窗口隐藏金额后，迷你窗口同步隐藏。
- 关闭迷你窗口同步关闭保存偏好。
- 关闭主窗口后隐藏到托盘，应用仍可运行。

测试没有访问或修改用户的实际浏览器档案与应用存档。未进行正式安装包构建、代码签名、发布或更新下载；未测量进程内存和 CPU。

## 查看与复验

```sh
npm run check
npm run dev
WAGECLAW_QA_URL=http://127.0.0.1:5173 WAGECLAW_QA_ELECTRON=1 node scripts/verify-lite.mjs
```

如果开发服务选择了其他端口，相应修改 `WAGECLAW_QA_URL`。浏览器测试需要本机 Google Chrome；Electron 测试不启动用户的日常档案。
