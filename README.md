# 忍了吧 WageClaw

将枯燥的打工时间转化为可视化的游戏化体验 —— 让每一分钟硬扛，都变成看得见的进度。

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | Vue 3 + TypeScript |
| 构建工具 | Vite 7 |
| 桌面端 | Electron 41 + electron-builder |
| 数据存储 | localStorage（key: `wageclaw-state-v3`） |
| 测试 | Vitest 4（`npm run test`，纯逻辑单测） |
| Lint | ESLint 9（`npm run lint`，flat config） |

## 快速开始

```bash
# 安装依赖
npm install

# Web 开发模式（HMR 热更新）
npm run dev

# TypeCheck
npm run typecheck

# 生产构建
npm run build

# Electron 桌面端
npm run electron

# macOS 打包（dmg + zip）
npm run dist:mac
```

## 核心功能

### 🏦 忍耐账户
- **按秒发薪**：月薪按工作日和上下班时间折算为每秒收入，实时跳动累计
- **动态领取**：今日可领数额每秒自动增长，随时"领工资"入账，领完归零重新累计
- **薪资隐私**：设置 → 外观可开启隐私模式，所有余额显示替换为 `¥****`
- **心愿碎片**：将心愿礼物拆分为碎片，用忍耐额度逐个点亮，进度可视化
- **记账系统**：收支/心愿/商城/桌宠多类别筛选，月度统计，分页列表

### 🛒 情绪补给仓
- **商城货架**：道具分即时止损、回血、反打扰、保命预案、大额奖励 5 类
- **双货币**：忍耐额度（wallet）和怨气（rage）双货币购买体系
- **背包 + 使用记录**：统一卡片式布局，子标签切换，与商城完全一致
- **分类筛选**：商品按类别过滤，每页 10 条分页

### 🏆 成就与每日任务
- **成就殿堂**：24 个成就分五大类（忍耐资产/怨气修行/软团养成/桌面战绩/心愿陈列），达成自动弹 toast 并发放爪币，桌宠页可查全部进度
- **每日任务**：任务池按日期确定性抽取 3 个，完成领爪币，零点自动刷新（首页任务卡）
- 全部数据驱动：新增成就/任务只需在 `src/data/achievements.ts` / `quests.ts` 加数据，详见 `docs/ARCHITECTURE.md`

### 👾 怨气桌宠
- **10 阶进化**：怨息雾团 → 电缆窥怨灵 → 便签角灵 → 键甲护怨使 → 工位怨王 → 会议碎阵师 → 墨怨法相 → 绩雷邪灵 → 玄玉怨尊 → 玄怨邪仙
- **5 维属性**：怨气、灵力、法力、饱食、亲密，全部可培养
- **触摸互动**：摸头/戳脸/揉肚/捏角/拽尾，每种有独特台词和反馈
- **炼化与投喂**：糟心事炼成怨气/灵力，供品投喂增强属性
- **召唤模式**：桌面悬浮小宠 + 全屏养成面板双模式

### 🎮 内置小游戏
- **桌面对练**：格斗对战，WASD 移动 + JKIL 招式 + Shift 格挡
- **五子棋**：与桌宠 AI 对弈，胜负统计
- **怨气闯关**：跑酷躲避，记分 + 最佳纪录

### 🥷 AI 职场忍者
- **三段式回复**：情绪确认 → 目标锚定 → 战术指导
- **情绪感知**：火大/稳如老狗/已经麻了三种状态匹配
- **敏感词过滤**：自动替换人名/公司/地点，安全发布

### 🌳 匿名树洞
- **社区信息流**：匿名工友吐槽和经历分享
- **安全脱敏**：发布前自动检测替换隐私信息

### ⏱ 倒计时同步
- 下班倒计时 / 距周六 / 距发薪日三重提醒
- 自然日 / 工作日两种口径切换
- 早中晚三段推送文案

### ⚙ 设置
- 个人资料：称呼、月薪、心愿、目标价格
- 工作节奏：上下班时间、发薪日
- 7 套主题：cyber / dawn / smog / paper / mint / peach / sky
- 数据管理：localStorage 持久化，支持数据重置

## 项目结构

```
src/
├── App.vue                    # 主组件，全部页面模板
├── main.ts                    # Vue 入口
├── styles.css                 # 全局样式 (~2777 行)
├── types.ts                   # TypeScript 类型定义
├── components/
│   └── PetSprite.vue          # 桌宠 SVG 组件
├── composables/
│   └── useWageClaw.ts         # 核心逻辑 (~1215 行)
└── data/
    └── catalog.ts             # 静态数据（桌宠阶段、商品、主题等）
electron/
├── main.cjs                   # Electron 主进程
└── preload.cjs                # 预加载脚本（上下文桥接）
```
