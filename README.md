# 忍了吧 WageClaw

一只陪你等下班的桌宠：偶尔告诉你今天的回报，和越来越近的休息。

## V2 桌宠版

- 今日已赚、本月已赚：按月薪和工作安排自动估算，无需领取。
- 下班倒计时：上班前、工作中、下班后和休息日分别展示。
- 下一个节假日、个人春节假期、预计年终奖发放倒计时；春节与年终奖按「月-日」填写，每年自动重复。
- 本地使用，无需登录、无需联网；工资信息不会发往服务端。
- 五套形象常驻桌面（卡皮巴拉、怨气团、懒猫、懒狗、老实牛）：单击看一句，双击打开收入与倒计时面板，拖动换位置。
- 鼠标悬停即浮出一张信息卡：今日已赚、距离下班、距离发薪、最近假期和距离年终奖。
- 每套形象有 10 个阶段，按当天班次进度平均切分自动进化；周末与休息日固定停在第一阶段。
- 工作时偶尔显示静音气泡，每天自动播报最多 32 次、两条之间至少间隔 10 分钟（随机 10–20 分钟）；右键可暂停一小时或今天安静。
- 面板按需打开、关闭后释放，桌宠与播报独立运行。
- 浅色／深色、即时金额隐藏、桌宠大小与置顶设置。
- 中国大陆 2026 年官方假期与补班、每周排班、个人日期覆盖。
- 旧版存档保留，沿用当前本地档案的工资、作息、发薪日及隐私偏好。

## 桌宠形象与进化

五套形象可随时切换，入口有三处：设置面板的「桌宠形象」下拉、托盘菜单的「切换形象」子菜单，以及浏览器 `?view=pet-preview` 预览页。选择结果写入 `pet.style`，重启后保留。

每套形象对应 10 个阶段。驱动源是**当天班次进度**，不是养成值：

```
阶段 = floor(班次已过比例 × 10) + 1     // 上限 10，下限 1
```

上班瞬间为第 1 阶，下班瞬间为第 10 阶，中间 10 等分。休息日与未到上班时间一律停在第 1 阶；跨过下班时间后停在第 10 阶。切换形象不会重置阶段，改作息或改夏季区间会立刻改变当前阶段。阶段每 30 秒校准一次，不做逐秒重绘。

素材分两种组织方式：卡皮巴拉、懒猫、懒狗、老实牛各用一张 2880×288 的合图（10 格 × 288px，Canvas 按 `(level-1)*288` 切片）；怨气团用 10 张独立 512×512 图。两条路径统一由 `petAssets.ts` 的 `petFrame()` 归一成 `{ url, sx, cell }`。

悬停信息卡是一个独立的透明窗口（280×158），只在鼠标进入桌宠可点击像素区时创建，离开 320ms 后销毁。桌宠上方放得下就放上方；有气泡占位时自动让到下方。浮层自身可悬停，鼠标移入不会闪断。

## 开发与验证

```sh
npm install
npm run dev
npm run electron
npm run check
```

预览服务默认使用 5173；如果端口被占用，启动 Electron 时通过 `WAGECLAW_DEV_SERVER_URL` 指定实际预览地址。

```sh
WAGECLAW_DEV_SERVER_URL=http://127.0.0.1:5174 npm run electron
```

浏览器及 Electron 场景验证（需要本机 Google Chrome；使用独立临时测试档案）：

```sh
WAGECLAW_QA_URL=http://127.0.0.1:5173 node scripts/verify-lite.mjs
WAGECLAW_QA_URL=http://127.0.0.1:5173 node scripts/verify-pet.mjs
WAGECLAW_QA_URL=http://127.0.0.1:5173 node scripts/verify-pet-features.mjs
```

截图保存在 `qa-shots/`，该目录不提交。`verify-lite.mjs` 验证浏览器面板；`verify-pet.mjs` 验证 Electron 桌宠与按需窗口；`verify-pet-features.mjs` 验证形象切换、十阶进化、夏季作息改阶段和悬停浮层。浏览器可通过 `?view=pet-preview` 预览形象和气泡，但不能代替真正的桌面窗口。

在受限环境（容器、沙箱）里跑 Electron 验证脚本时，额外设置 `WAGECLAW_QA_NO_SANDBOX=1`，脚本会给 Electron 补上 `--no-sandbox`；普通终端下无需设置。

## 计算口径

月薪除以当月计划工作日数得到日估算收入，乘以当天班次完成比例得到今日收入。本月收入为已结束计划工作日的收入加上今日收入，最高为月薪。班次是单段连续的，**午休照常计入工时**（不扣除、不暂停，每分钟增量全天恒定），只支持同一天内的上下班时间。休息日今日收入为零，不计算加班费。

作息支持两套：常规作息全年生效，夏季作息在设定的月-日区间内（含起止当天、每年自动重复）覆盖常规作息。默认出厂值为常规 08:30–17:30、夏季 05-01～10-01 的 08:30–18:00；区间留空即全年使用常规作息。当天用哪一套由 `activeShift` 判定，收入进度、下班倒计时和播报节点共用同一结果。

这些数字是估算，不是银行到账。修改工资或排班会重算当月。关闭、重启和睡眠唤醒后按当前时间直接恢复，无每秒存款和重复领取。

工作日优先级：具体日期覆盖 → 个人春节假期 → 官方放假及补班 → 每周排班。个人春节只填开始日期时，仅将当天记为休息日。

春节假期与年终奖发放日都按「月-日」保存，**每年重复**：假期结束后自动滚到下一年的倒数，不会停在「已结束」。旧版存档里的完整日期（如 `2027-02-04`）在读取时自动收敛成 `02-04`。

2026 年假期来源：[国务院办公厅关于2026年部分节假日安排的通知](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)。未收录年份不推测放假日期，收入暂按个人排班估算并提示缺少调休资料。

年终奖日期和金额均为个人预计，不计入工资；只有用户手动标记才显示已收到。「已收到」标记只在本轮发放周期内有效（发放日当天起 30 天），跨年后自动作废，因此不会在下一年发放日误报已收到。

## 数据与更新

桌面配置迁移至 Electron 用户数据目录下的 `wageclaw-desktop-v2.json`，由独立服务串行原子写入；浏览器预览继续使用 `wageclaw-lite-v1:local` 或对应用户隔离键。首次桌面迁移只读取旧版当前档案，原 localStorage 保留。原 `wageclaw-state-v3` 系列存档不删除。退出登录状态下不擅自选取其他账户数据。损坏档案会进入恢复提示，覆盖前需通过恢复默认操作保存原始备份。

设置可导出当前档案及其旧版存档。恢复默认前会保留本机备份；桌面版支持导入旧轻量版或新版导出文件；导入需确认，替换前保留原始完整备份。

更新仅在设置中手动检查。通过 `electron/app-config.json` 或 `WAGECLAW_UPDATE_URL` 配置更新地址，失败不影响本地功能。
