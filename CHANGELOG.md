# Changelog

All notable changes to WageClaw will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.3.0] - 2026-05-27

### Added
- Work event system with random workplace incidents and choice-based outcomes
- Paw currency (爪币) with daily attendance, interaction, and event earning caps
- Desktop blackout overlay — full-screen calming animation for rage overflow
- Pet ricochet, storm, and nuke animation sequences
- Pet blood pressure stat with ideal/min/max ranges
- Supply depot redesign with wish shop and supply shop tabs
- Onboarding flow for first-time users

### Changed
- Major UI overhaul across all screens
- Pet evolution stages expanded with unique palettes and sigils
- Transaction system now supports paw currency ledger

## [0.2.0] - 2026-05-17

### Added
- Wish fragment system with progress tracking
- Dual currency (wallet + rage) mall purchasing
- Inventory and usage log with unified card layout
- Category filtering and pagination for mall items

### Changed
- Refined wish completion flow
- Improved pet interaction feedback

## [0.1.0] - 2026-05-09

### Added
- Initial Electron packaging (Windows NSIS, macOS DMG)
- Theme system with 7 variants (cyber, dawn, smog, paper, mint, peach, sky)
- Privacy mode for salary display

### Fixed
- Electron build configuration issues

## [0.0.1] - 2026-05-01

### Added
- Core salary-per-second calculation engine
- 10-stage pet evolution system
- Mini games: desk duel, gomoku, rage runner
- AI Office Ninja with three-stage responses
- Anonymous community treehole
- Triple countdown (off-work, Saturday, payday)
- Settings with profile, schedule, and data management
