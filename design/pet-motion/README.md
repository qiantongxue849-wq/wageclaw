# 卡皮巴拉真实姿态动画样片

## 新增三组动作（2026-09-27）

在当前精修预览中加入「困困哈欠」「开心蹭蹭」「动动耳朵」，保留原回应、眨眼和上一版对照。每组使用内置 ImageGen 参照 V2 生成独立的 4×4 / 16 姿态透明图，没有用整张位图缩放代替动作。

- 原稿：`capybara-source-{yawn,nuzzle,ears}.png`；完整提示词：`prompt-{yawn,nuzzle,ears}.txt`。
- 播放素材：`capybara-poses-{yawn,nuzzle,ears}.webp`，每组约 358–374 KiB，定位信息在相应 `frames-*.json`。
- 重建：`node scripts/build-motion-study.mjs --action=yawn`（同样支持 nuzzle、ears）。
- 动作选择较连贯的前半段姿态、停留后沿原帧收回，避免末尾不同静止画面引起跳动；每组首尾精确复用自己的第 0 帧。切换动作组时仍可能有细小外形差异。
- 点击动作按钮切换，点角色重播所选动作。首次点击才请求该组素材，已加载组在当前页面复用；播放结束无持续动画计时器。
- 停止、滑杆查看、隐藏页面和减少动态效果都会取消待播放请求；连续点击只执行最后一次选择。
- 动图导出：`capybara-motion-{yawn,nuzzle,ears}.gif`，与实际播放器帧序和时长一致，末尾加 1.4 秒静止供预览。
- 验证：`node scripts/verify-motion-actions.mjs` 检查懒加载、脚掌定位、精确回到静止、重播、快速切换、加载途中停止、128px、深色、窄屏和减少动态效果。三组地面均为 y=266，脚掌横向误差最多 1px；原回应与眨眼回归也通过。

当前仍为独立动作样片，未替换正式桌宠；其他角色和形态保持原样。AI 姿态间仍可能出现少量纹理变化。

## 当前结论

上一版 `src/lite/petMotion.ts` 用单张位图的整体缩放和位移做反馈，没有重绘眼睑、头部和肢体。
本目录试验连续姿态素材：16 张新绘制动作帧，保留原卡皮巴拉基础形态作为身份参考，眼睛与头部在不同帧中实际变化。播放代码仅裁切帧、对齐中心和落脚位置，不合成变形或插值帧。

这不是生产级完整角色动画。AI 生成的帧之间仍有细微纹理和轮廓漂移；没有完整走路、趴下或伸懒腰动作，未扩展到五组十种形态，未替换当前应用的动画。保留独立样片是为了让动作质量先可见，不将原效果换成另一种未验收的效果。

## 文件

- `index.html`：旧版整图变形与新逐帧样片的可播放对比，可调逐帧和实际尺寸。
- `capybara-source.png`：内置 ImageGen 生成的原始 4×4 连续姿态表。
- `prompt.txt`：完整生成提示词。参考图为 `src/assets/pet/capybara-idle.webp`。
- `capybara-poses.webp`、`frames.json`：压缩输出与落脚对齐数据。
- `capybara-motion-study.gif`：浏览器实际绘制结果的循环展示导出，额外停留后回到第一帧。此 GIF 用于样片查看，正式播放建议按需单次而非一直循环。

生成路径：内置 `image_gen`，没有调用付费 Weave 视频流程，没有使用 CLI/API fallback。原始生成文件在 Codex generated_images 内另有保留。

## 验证

运行 `node scripts/verify-motion-study.mjs`：16 帧像素确实不同、落脚位置偏差不超过 2px、画布没有 CSS transform、单次播放结束释放定时器并回到第一帧、尊重减少动态效果。
没有安装额外录像依赖，GIF 由现有 sharp 编码。

## 后续制作标准

每个角色先选一个能表现肢体动作的基础造型，再制作可自然衔接的待机、被摸、眨眼、转头、趴下、伸懒腰、走路；不要把十种造型差异当成十帧动画。细小表情可以用精修逐帧，全身连续运动需要稳定分层/骨骼素材或受控的连续动画输出。生成帧必须逐帧修正角色比例、地面接触点和纹理漂移，再作为正式动画接入。
