# 二至十级逐帧动作

已接入五个角色的 45 个后续形象，每套 24 张真正重绘姿态。一级素材保持原样，程序不再用波浪、局部采样或位图扭曲生成动作。

- `references/`：各等级原始形象参考。
- `*-source.png`：实际采用的透明动作原图。
- `*-prompt.txt`：每套最终采用的完整提示词，使用内置 imagegen 生成。
- `*-draft.png`：未采用草稿，不进入产品。
- `layouts.json`：切分布局；怨气团十级只裁掉图集外围空白以校准网格，不改画面。
- `authored-motion.gif`：二级、十级的三类姿态预览，使用产品图集与定位数据。
- `index.html`：开发模式检查页，直接使用正式 Vue 播放组件。

导出：`node scripts/build-stage-motion.mjs`。仅做透明间隔切帧、WebP 编码、大小和落点标定，不制造新姿态。产品资源位于 `src/assets/pet-motion/stages/`。为保留手持杯子，卡皮巴拉八级、懒狗九级不播放原图集末尾的双臂伸展帧。

验收：45 套图集、1,080 张有效姿态，250 组应用互动检查，69 项单元测试，生产构建和原生桌宠联动检查。生成画面仍可能有细微纹理差异。
